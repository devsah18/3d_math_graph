# GraphX 3D

## Interactive 3D Mathematics Visualizer

GraphX 3D is an open-source web application that allows users to enter mathematical equations and watch their 3D graphs being generated progressively.

The goal is to make mathematical functions easier to understand through interactive visualization.

---

## ✨ Features

- Interactive 3D coordinate system
- X, Y and Z axes
- Mathematical equation input
- Progressive graph generation
- Pause and resume
- Reset graph
- Adjustable animation speed
- Adjustable graph range
- Adjustable resolution
- Mouse rotation
- Zoom
- Pan
- Live X, Y and Z coordinates
- Generation progress
- Example equations
- Responsive interface
- GitHub Pages compatible
- No backend required

---

## 🧮 Example Equations

Try:

```text
x^2 + y^2
````

```text
sin(x) * cos(y)
```

```text
x * y
```

```text
sqrt(x^2 + y^2)
```

```text
sin(sqrt(x^2 + y^2))
```

You can also enter:

```text
z = x^2 + y^2
```

## 🚀 Run Locally

Download or clone the repository.

Open:

```text
index.html
```

in a modern web browser.

No server is required.

---

## 🌐 GitHub Pages

This project can be hosted using GitHub Pages.

1. Create a GitHub repository.
2. Upload:

```text
index.html
style.css
script.js
README.md
```

3. Open repository settings.
4. Go to:

```text
Pages
```

5. Select the main branch.
6. Select the root folder.
7. Save.

GitHub will provide a public website URL.
